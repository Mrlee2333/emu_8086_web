# Audit — v1.5.0

- Branch: `feature/corpus-conformance-v1.5.0`
- Date: 2026-09-28
- Machine: Mac arm64 (Apple M4, 16 GB) · macOS 27.0 · `bun 1.4.2` · median of 15 runs
- Benchmark: `bun audit/bench.mjs --runs 15` (the frozen workload from
  `audit/README.md`, unchanged since v1.3.2)
- v1.4.2 measured in the same session from a `git worktree` at the `v1.4.2` tag,
  interleaved with the release branch, because a number recorded weeks ago on a
  different machine is not a baseline
- Scope: emulator step loop, step-back snapshot cost, console output cost,
  memory search, first-load bundle, and the memory bounds

## vs v1.4.2

- **The benchmark caught a real regression, and it is fixed.** The first
  implementation of constant expressions put a symbol-table lookup on the path
  every operand read takes, which cost **28 % of step throughput** (5.16 ms →
  6.63 ms on the same machine in the same session). `readOperand` now consults
  the table only for a token that could be mistaken for a number — which is
  exactly a bare name ending in a radix letter, the case that made `EACH EQU 4`
  read as `0xEAC` in the first place. Immediate and register operands skip the
  table entirely, and the loop is back inside the noise band. The lesson is
  worth keeping: a property read that looks free is not free when it is on the
  fetch-decode-execute path, and only an interleaved same-session baseline
  catches it.
- **No memory bound moved.** Step-back still retains 256 snapshots of 64 KiB
  (16.0 MiB), `dataStack` still caps at 4096 entries, `callStack` still halts
  with an error at 8192, and the console still keeps the newest 2000 lines. The
  DOS file system is new and is *not* rewound by Step Back: it is a store of
  whole files rather than machine registers, and copying every file into every
  snapshot would cost more than the feature is worth. The port latch *is*
  captured, so stepping back over an `OUT` reads the port as it stood.
- **Conformance is now measured rather than asserted.** 177 new tests, of which
  138 are 136 third-party programs run to completion with their output compared
  character for character, and 39 are focused tests naming each new behaviour
  (constant expressions, the calling convention, shift and rotate flags, `DAA`,
  the file services, the polling services). The corpus suite costs about
  0.2 s, so it can sit in the default test run rather than behind a flag.
- **Bundle is flat.** 680,961 B → 682,728 B on `/`, +1,767 B: the expression
  evaluator, the file system and the extra services are all in the emulator,
  which is already loaded, and the only new code on the IDE path is a
  `[...]`→address helper. The budget gate still passes with 37 KB to spare.
- **The console is 1 microsecond slower per 1000 reads**, which is not a
  regression worth acting on: `machine.output` is memoized behind a version
  counter, so this measures the counter check, and v1.4.2's own audit measured
  the same path at 0.0075 ms. The three runs disagree in both directions.

## What changed, and what it cost

| Change | Cost |
|---|---|
| `EQU`, constant expressions, `expr.ts` | 2 passes over the source at assembly time (assembly happens once per edit, not per step) |
| `CALL` pushes the return address | 2 memory writes per call; the step loop is unaffected |
| `DosFiles` | Lives for the life of a machine, capped at 32 open handles; not in step-back |
| Port latch | One `Map` entry per port touched, copied per snapshot (a few entries, not 64 KiB) |
| Corpus fixtures | 1.0 MiB in the repository, 0.2 s in the test run, no client bundle cost |

## Reproduce

```sh
bun audit/bench.mjs --runs 15                 # this version
git worktree add /tmp/emu142 v1.4.2           # the previous version
cd /tmp/emu142 && bun audit/bench.mjs --runs 15
bun test lib electron
bun run verify
```

The corpus number needs a checkout of the corpus, which is not vendored in
full (only the 136 selected fixtures are):

```sh
git clone https://github.com/Amey-Thakur/8086-ASSEMBLY-LANGUAGE-PROGRAMS /tmp/corpus
bun scripts/conformance-report.ts /tmp/corpus/Source Code
```
